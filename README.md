# أسطرلاب — أطلس السماء العربي

تطبيق أندرويد + ويب تقدّمي (PWA) يعمل **بلا إنترنت**: سماء مدينتك بنجومها وكوكباتها وأسمائها العربية، الشمس والقمر والكواكب في أماكنها الحقيقية، منازل القمر الثماني والعشرون، طرق الاهتداء بالنجوم، أسطرلاب تفاعلي كامل بدروسه، متابعة محطة الفضاء الدولية وأقمار ستارلينك، ودروس فضاء مبسطة للأطفال.

صمّمه وطوّره **مصطفى محمود** (محقق تراث إسلامي وباحث وخبير ذكاء اصطناعي).

## البناء
- `www/` تطبيق الويب كاملًا (HTML/JS/CSS بلا أي خطوة بناء).
- `android/` غلاف WebView بسيط يحمل التطبيق من أصوله المحلية.
- GitHub Actions يبني `astrolab.apk` وينشره في Releases عند كل دفع إلى main.

## المصادر المفتوحة والتراخيص
- [Astronomy Engine](https://github.com/cosinekitty/astronomy) — MIT — حسابات الشمس والقمر والكواكب.
- بيانات النجوم والكوكبات من [d3-celestial](https://github.com/ofrohn/d3-celestial) — BSD-3-Clause — أصلها كتالوجا Hipparcos وYale.
- [satellite.js](https://github.com/shashwatak/satellite-js) — MIT — حساب مدارات الأقمار، وبيانات TLE من [CelesTrak](https://celestrak.org).
- نسيج الأرض من [Poly Haven](https://polyhaven.com) — CC0.
- طبقة الغيوم (عند توفر إنترنت فقط) من [Open-Meteo](https://open-meteo.com) — CC BY 4.0.
- النصوص العربية والدروس والتصميم والكود: أصلية خاصة بهذا التطبيق.

طبقة الغيوم وتحديث مدارات الأقمار هما الشيئان الوحيدان اللذان يستخدمان الإنترنت، وكلاهما اختياري؛ كل ما عداهما يعمل دون اتصال.
